# Game sprite style

The knight restyled for the [game sprite style plan](../../docs/plans/2026-11-04-game-sprite-style.md): a bigger
great helm and steel shaded from one light, in the side and three-quarter views. Not kept (its judge round missed).

- `knight-skin.json`: the restyled skin; copy it over `examples/knight/skin.json` to see it on the page.
- `restyle.py`: the hand-drawn part grids, written into a skin: `python3 restyle.py <skin.json> <out.json>`.
